本版从这里接手上游停维护的项目，是 Reasonix Studio 的完整版本：侧栏与图标栏合成一张表，对话轨改成刻度尺，会话之间可以互相派活并有独立的「会话互聊」设置分区；新建会话直接进窗口、落在「任务」组，再由输入框上方的项目药丸决定它属于哪个项目；任务会话按日期归档，首轮发言后自动命名；社区市场和账号一起移除，插件安装保留。

## 新增

- 侧栏和图标栏画同一张表里的行，两处不再各说各的，也不会把同一个入口画两次 (d30a3c2)
- 自定义导航栏：右键点图标栏打开，一个列表管顺序与显隐，拖动时被越过的行让位，松手才落盘 (d30a3c2)
- 派活时可以给目标会话起一个名字，同一个项目里的几个会话不再读起来像一个；新设置 `peers.incoming` 决定别的会话发来的消息要不要弹授权卡 (9c34528)
- 跨项目派发三档：始终允许 / 配对允许 / 禁止（`peers.cross_project`，默认始终允许）；配对允许只派给本会话已在那个项目打开的窗格 (c6a50b4)
- 派发带角色时，目标会话以角色为名——侧边栏里读到的就是「组员B · VR面板式」，不是文件名 (c6a50b4)
- 派发方的面板挂上会话互聊状态条：每条派发出去的会话一行，实时显示等待、处理中、已回信，点一下就能跳过去 (40335ab)
- 设置新增一级分区「会话互聊」：会话间消息、放行的项目、跨项目派发三档、引用历史会话的长度、子代理写入范围，外加两个派发上限（穿透层数、同时派发数） (90fe800)
- **新建会话直接进会话窗口**：不再先弹选择框，新对话落在内核自己的工作区，进侧栏的「任务」组；归属由输入框上方的项目药丸决定 (f262596 前)
- **输入框上方的项目药丸**：新对话的引导——列出记住的项目（搜索、当前标记）、新建空白项目（起名+选位置，浏览器端没有选择器时回退手输路径）、使用现有文件夹、不使用项目；对话一旦开始（或已放置）药丸就退场 (4f9c204)
- **任务会话按日期归档**：任务会话的记录落在 `…/sessions/2026/11/14/` 这样的日期目录里，像日历一样翻；项目会话保持平铺 (87334c4)
- **首轮发言自动命名**：第一轮发出时就向标题模型要一个名字，回答还在生成，侧栏读到的已经是真名字；标题模型由 `agent.title_model` 指定，没配就不自动起名 (161a45c)
- **仪表栏统计「对话轮次」**：只数你发起的轮——发言中途的插话和折叠摘要不算，从记录重新推导 (161a45c)
- **本机终端前端的网页端可以添加模型源**：授权跟随监听地址——loopback 才放行写入，后开的窗格同样继承 (0f9892d)
- 右侧控制台的启动器撑满自己所在的列，不再被 420px 一类的上限裁着 (0166c60f)；记忆正文与编辑器同样撑满 (83c8c4d6)

## 变更

- 右边缘的对话轨改成一把尺子：刻度密集、右端对齐，视口是一格更深的刻度而不是一条色带 (d30a3c2)
- 会话树分成「项目」「任务」两组：分组标题是纯文字——「项目」「任务」，点按即折叠本组；任务组的会话直接挂在「任务」标题下，不再有中间的文件夹行 (cd2267b)
- 项目行带着文件夹图标：折角 + 文件夹 + 名字；任务组的会话行无图标 (14cd2c2)
- 窗口栏对任务会话只显示会话标题——不属于任何项目的对话不再借「auto」占一个位置 (a6a4e65)
- 「任务列表」是标签不是按钮：悬停不再出现指针与可点击的错觉 (cb2770d)
- 范围菜单从点击处向右下展开，宽度按最长的行收：右侧一列是数字，最近的方向箭头跟着「最近」两个字走 (4f9c204)
- dock 与侧栏的滑出动画换成更柔和的缓动 (a42b9bb)
- 思考卡的「实时」模式与「展开」一样不限窗口高度 (14939ca1)；思考文字有自己的字重，轻体模式下更轻 (599badfd)
- 设置行的分段控件对齐行的边缘 (dc2c90a2)；写锁的搜索结果落到承载它的会话页 (2e2e13ce)
- 权限与安全›扩展范围的项目列表挂到 body 上，不再被设置页的滚动容器裁切 (d0a0c221)

## 修复

- 打开设置后右上角的最小化、最大化、关闭重新能按：此前按下去变成拖动窗口，双击标题栏恢复大小也一并回来 (d5436da)
- 项目药丸的下拉箭头回到标签同一行，下拉列表里带「N 项例外」徽章的行不再错位 (d5436da)
- 右侧控制台的拖拽分栏条在新的网格布局下保持整列高度——此前它塌成一条看不见的缝，右栏完全拉不动 (a6a4e65)
- 任务文件夹的复选框与键盘焦点在各折叠状态下都能落回一个真的能按的控件 (d30a3c2)
- 图标栏的「用量」「扩展」在打开对应设置页时正常显示选中态 (933e5d9)
- 契约测试跟随新的落地契约：记住的项目不再接住新会话，重排记住列表也不再决定默认落地处 (f262596)

## 移除

- 社区市场整体移除；账号本身也移除：关于页、云端备份、在线状态点，以及关于里的社区、赞助与抖音入口 (ccb42ee)
- 最近页：最近现在是一种排序，不再是一个页面 (d30a3c2)
- 先打开一个项目的引导页：归属由输入框上方的项目药丸回答，空会话只自我介绍 (4f9c204)

## 升级须知

- 任务会话从此写入日期目录；旧的任务会话文件仍在原处，侧栏照常列出它们 (87334c4)
- 自动命名需要 `agent.title_model` 指向一个模型，没配就不自动起名 (161a45c)
- 市场没了，已装好的插件照常工作；云端备份随账号一起移除，本地文件备份不受影响 (ccb42ee)
- `agent.write_lease` 的搜索结果指向会话页；`desktop.update_mode` 的搜索指向维持原处 (0f9892d)

Upstream stopped maintaining the project after 2.61.0; this Reasonix Studio release
picks it up and carries the full fork.

## New

- The sidebar and the icon rail draw the rows of one table; a custom nav orders
  them (d30a3c2)
- The conversation rail becomes a ruler; 最近 becomes an ordering inside the
  filter menu (d30a3c2)
- Sessions dispatch to each other with a dedicated 会话互聊 settings section, a
  three-way cross-project policy, role-named targets and a live dispatch bar
  (40335ab)
- A new conversation opens straight into the window, lands in the 任务 group,
  and the project pill above the composer decides where it belongs — remembered
  projects (search, current mark), a blank project (name + folder), an existing
  folder, or 不使用项目; once placed the pill leaves (4f9c204)
- Task conversations file themselves by date (…/2026/11/14/); project sessions
  stay flat (87334c4)
- The first turn asks the title model while it runs, so the sidebar reads a real
  name (161a45c); `agent.title_model` gates it — none, no unprompted naming
- The meter rail counts the turns the person authored (4cb4a9e6) — steers and
  fold digests do not
- A loopback terminal frontend can add a model source (68df8bbf); later panes
  inherit the grant (7a19686a)
- The workbench launcher fills its column (0166c60f); the memory editors fill
  theirs (83c8c4d6); the dock slides ease gently (450f2d1b); a live thought uses
  the whole window (14939ca1); the thought text carries its own weight token
  (599badfd)
- The 扩展范围 pill portals its project list out of the settings scroll box
  (d0a0c221)

## Changed

- The session tree's two groups 项目 / 任务 are plain labels that fold their
  group (cd2267b); task conversations hang directly under 任务 with no folder row
- The project row carries its folder icon again (14cd2c2); the window bar names
  a task conversation by its title alone (no auto crumb) (a6a4e65)
- 任务列表 is a label, not a button that only looked clickable (cb2770d)
- The scope menu opens at the click toward the bottom-right, sized to its longest
  row (4f9c204); the arrow rides the 最近 label and the count column stays
  numbers only
- The settings rows' segmented control lands at the row's edge (dc2c90a2); the
  write-lease search result moved to the session page that hosts it (2e2e13ce)

## Fixed

- The settings windowbar's 最小化 / 最大化 / 关闭 click again while 设置 is open
  (d5436da)
- The scope pill's chevron and its exception chips sit where they belong
  (d5436da)
- The right console's drag divider keeps its full column height under the new
  grid — before, it collapsed to an invisible sliver and the sidebar would not
  resize (a6a4e65)
- The contract tests follow the new landing: a remembered folder no longer
  catches a fresh conversation, and reordering the list no longer decides the
  default (f262596)

## Removed

- The community market, the account (about page, cloud backup, online dot), the
  最近 page (d30a3c2), and the 先打开一个项目 onboarding hero (4f9c204)

## Upgrade notes

- Task conversations write into date folders; older files stay where they are and
  the sidebar still lists them (87334c4)
- Auto-naming needs `agent.title_model` pointed at a model (161a45c)
- Installed plugins keep working; cloud backup went with the account — local file
  backup is untouched (ccb42ee)
