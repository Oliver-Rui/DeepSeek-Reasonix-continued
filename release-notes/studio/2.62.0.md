上游 2.61.0 之后项目已声明停止维护，本版从这里接手。本版是 Reasonix Studio Tweaks 的第一版：侧栏与图标栏合成一张表，对话轨改成刻度尺，最近排序进筛选菜单，会话之间可以互相派活——派发有了三档跨项目策略、以角色为名的目标会话和自己的设置分区，新建会话先选项目；社区市场和账号一起移除，插件安装保留。

## 新增

- 侧栏和图标栏画同一张表里的行，两处不再各说各的，也不会把同一个入口画两次 (d30a3c2)
- 自定义导航栏：右键点图标栏打开，一个列表管顺序与显隐，拖动时被越过的行让位，松手才落盘 (d30a3c2)
- 最近排序挪进会话筛选菜单，就在全部下面：点一次最新在前，再一次最旧在前，第三次不排序，右边的箭头始终说明是哪种 (d30a3c2)
- 派活时可以给目标会话起一个名字，同一个项目里的几个会话不再读起来像一个；新设置 `peers.incoming` 决定别的会话发来的消息要不要弹授权卡 (9c34528)
- 会话树分成「项目」「任务」两组，各有分组标题：记住的项目在上，窗口自己打开的文件夹——不属于任何项目的会话——在下 (1e4451d)
- 「新建会话」先弹「选择项目」：搜索、本地与远程项目、创建项目，以及「不在项目中工作」，它把会话开在内核自己的非项目文件夹里，落进「任务」组 (75b11b9)
- 跨项目派发三档：始终允许 / 配对允许 / 禁止（`peers.cross_project`，默认始终允许）；配对允许只派给本会话已在那个项目打开的窗格 (c6a50b4)
- 派发带角色时，目标会话以角色为名——侧边栏里读到的就是「组员B · VR面板式」，不是文件名 (c6a50b4)
- 派发方的面板挂上会话互聊状态条：每条派发出去的会话一行，实时显示等待、处理中、已回信，点一下就能跳过去 (40335ab)
- 设置新增一级分区「会话互聊」：会话间消息、放行的项目、引用历史会话的长度、子代理写入范围，外加两个从未露出过的派发上限（穿透层数、同时派发数） (90fe800)
- 设置 › 数据 里的本地文件备份仍可导出、导入与预览，分组说明跟着一起走 (ccb42ee)

## 变更

- 右边缘的对话轨改成一把尺子：刻度密集、右端对齐，视口是一格更深的刻度而不是一条色带；指到某条消息时只有那一条拉长，文字卡片贴在它左边 (d30a3c2)
- 图标栏只有两种答案：工作区栏收起时出现，展开时让位；存着的旧值读回来就是收起这一种 (d30a3c2)
- 项目行长出复选框，选中它就是选中这个文件夹当前显示的全部行；选择本机会话挪到折叠全部旁边 (d30a3c2)
- 窗口自己打开的那个文件夹标成任务，放在项目下面一段，不再和项目混成一条 (d30a3c2)
- 分组头变成控件：「项目 ⌄」「任务 ⌄」点按即折叠/展开本组，文件夹与任务图标、工具栏上独立的收起按钮随之退场，项目行也不再带文件夹图标 (92d7453)
- 插件安装的入口收成一个添加菜单：仓库地址、本地文件夹、外部服务，市场那一项随市场一起走了 (ccb42ee)

## 修复

- 窗口在 1400px 宽下打开文件面板：图标栏此时是收起的，走侧栏那一行，不再点一个在屏幕外的按钮 (466dbfd)
- 本版新引入的规范问题一并收拾：文档段落宽度、重复的 `!important`、超长注释、Windows 上会失败的临时目录 (adac25d)
- 两个越过 800 行的文件把常量与参数搬回各自的模块，行为不变 (b6fe39f)
- 任务文件夹的复选框与键盘焦点在各折叠状态下都能落回一个真的能按的控件 (d30a3c2)
- 打开设置后右上角的最小化、最大化、关闭重新能按：此前按下去变成拖动窗口，双击标题栏恢复大小也一并回来 (d5436da)
- 项目药丸的下拉箭头回到标签同一行，下拉列表里带「N 项例外」徽章的行不再错位 (d5436da)
- 图标栏的「用量」「扩展」在打开对应设置页时正常显示选中态：此前两行的分区名和设置页用的 id 不同，选中样式永远落不下来 (933e5d9)

## 移除

- 社区市场整体移除：浏览、详情、安装确认、发布、我的发布、投票，以及通向它们的登录提示 (ccb42ee)
- 账号本身也移除：关于页、登录后的云端备份、窗口顶部的在线状态点，`Account.tsx` 一并删除 (ccb42ee)
- 关于里的社区与贡献者、赞助：QQ 群、Discord、议题入口、贡献者名单、PayPal 与微信、支付宝收款码，连同它们的样式、图片与英文词条 (d30a3c2)
- 抖音入口（账号、复制按钮、二维码），更早一批同样的工作里已经删掉 (d30a3c2)
- 最近页：最近现在是一种排序，不再是一个页面 (d30a3c2)

## 升级须知

- 市场没了，已经装好的插件照常工作；新的插件仍可从仓库地址、本地文件夹、外部服务或备份文件装进来 (ccb42ee)
- 云端备份随账号一起移除，先前传上去的备份不再能从界面里取回；本地文件备份不受影响 (ccb42ee)
- 存过「图标栏常显」的机器读回来是「收起时显示」，因为常显会把同样的六个入口在屏幕上画两次 (d30a3c2)
- 别的会话发来的消息要不要弹授权卡，从此由 `peers.incoming` 决定，不再只看派活开关：默认的 `dispatch` 只放行已配对的会话（2.60.0 说的「开关开着就直通模型」不再成立），要接住任意会话就把 `incoming` 设成 `always` (9c34528)

Upstream stopped maintaining the project after 2.61.0, so this first Reasonix Studio Tweaks release picks it up.

## New

- The sidebar and the icon rail draw the rows of one table, so the two can no longer disagree or offer one destination twice (d30a3c2)
- 自定义导航栏 opens on a right click on the bar: one list orders the rows and hides them, crossed rows give way while dragging, and the order is written on release (d30a3c2)
- 最近 ordering moved into the session filter menu, under 全部: newest first, then oldest first, then unsorted, with an arrow that always says which (d30a3c2)
- A dispatch may name the session it opens, so several sessions in one project do not read as one; a new `peers.incoming` setting decides whether a message from another session shows the approval card (9c34528)
- The session tree reads as two named groups — 项目 over the remembered projects, 任务 over the window's own folder — each with its own heading (1e4451d)
- 新建会话 opens a 选择项目 card first: search, local and remote projects, 创建项目, and 不在项目中工作, which opens the session in the kernel's own non-project folder, where the 任务 group lists it (75b11b9)
- Cross-project dispatch has three answers: always / paired only / never (`peers.cross_project`, default always); paired sends only to a pane this session already has open in that project (c6a50b4)
- A dispatch that names a role names the pane it opened — the sidebar reads 组员B · VR面板式, not a file stem (c6a50b4)
- The dispatching pane grows a 会话互聊 bar: one row per dispatched session, live waiting / working / replied states, one click to jump over (40335ab)
- Settings gains a top-level 会话互聊 section: the messages switches, 放行的项目, the quoted-session context, the subagent write scope, plus two dispatch ceilings that had no UI (dispatch depth, concurrent dispatched sessions) (90fe800)
- The local file backup under 设置 › 数据 still exports, imports and previews, with its group notes beside it (ccb42ee)

## Changed

- The conversation rail on the right edge is a ruler: dense ticks sharing one right edge, the viewport one darker tick instead of a painted band, and only the pointed tick stretches, with its text in a card to its left (d30a3c2)
- The icon bar has two answers: it appears while the workspace column is shut and gives way while it is open; a stored "always" reads back as the first (d30a3c2)
- A project row grows a checkbox that picks every row the folder shows, and 选择本机会话 moves beside fold-all (d30a3c2)
- The folder the window itself opened in is announced as 任务 below the projects instead of reading as one of them (d30a3c2)
- The group heads are controls now: 项目 ⌄ and 任务 ⌄ fold and unfold their own group on click, the folder and tasks icons and the toolbar's separate fold-all control retire with them, and project rows drop their folder icon (92d7453)
- Every way into the extensions list sits behind one add menu — a repository address, a local folder, a connected service — with the market entry gone with the market (ccb42ee)

## Fixed

- Opening the files panel in a 1400px window: the icon bar is folded there, so the guard takes the sidebar's row instead of clicking a button that is off screen (466dbfd)
- The repo standards this revision had broken are clean again: prose width, a duplicate `!important`, over-long comments, and a temporary directory whose cleanup fails on Windows (adac25d)
- Two files that crossed 800 lines moved a constant and a props table back into their own modules, with no behaviour change (b6fe39f)
- The 任务 folder's checkbox and keyboard focus land on a control that can actually be pressed at every fold state (d30a3c2)
- The settings windowbar's 最小化 / 最大化 / 关闭 click again while 设置 is open — pressing them dragged the window instead, and the double-click zoom went with them (d5436da)
- The scope pill's chevron stays on the label's line, and a dropdown row carrying an 「N 项例外」 chip keeps its columns (d5436da)
- The rail's 用量 and 扩展 rows light up while the settings page they name is open: the rows and the settings sections used two different vocabularies, so the selection style could never land (933e5d9)

## Removed

- The community market is gone: browse, detail, install confirmation, publishing, your own packages, voting, and the sign-in prompts that led to them (ccb42ee)
- So is the account: the About page, the cloud backup behind a signed-in account, the presence dot in the window chrome, and `Account.tsx` itself (ccb42ee)
- 社区与贡献者 and 赞助 in 关于: the QQ group, Discord, the issues entry, the contributor list, the PayPal, WeChat and Alipay codes, with their styles, images and English strings (d30a3c2)
- The 抖音 entry (account id, copy button, QR code), removed in the same earlier round (d30a3c2)
- The 最近 page: 最近 is an ordering now, not a page (d30a3c2)

## Upgrade notes

- The market is gone, so plugins already installed keep working, and a new one still arrives from a repository address, a local folder, a connected service or a backup file (ccb42ee)
- The cloud backup went with the account, so backups uploaded earlier cannot be fetched from the interface any more; the local file backup is unaffected (ccb42ee)
- A machine that stored "always show the icon bar" reads back as "while the workspace column is shut", because always-on drew the same six entries on screen twice (d30a3c2)
- Whether a message from another session shows the approval card is decided by `peers.incoming` now, not by the dispatch switch alone: the default `dispatch` takes only a paired session, so 2.60.0's "straight to the model while the switch is on" no longer holds; set `incoming = "always"` to take any of your sessions (9c34528)
